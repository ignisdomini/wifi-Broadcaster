РАДИОИНФОРМАТОР — установка на хостинг
===============================

Что нужно от хостинга
---------------------
  PHP 8.0 или новее, расширения pdo_mysql и mbstring
  MySQL 5.7 / 8.0 или MariaDB 10.3+
  Возможность записи в корень сайта (на время установки)

Ни composer, ни node, ни консоль не требуются. Расширение gd и права на
запись в каталоги больше не нужны: сайт не принимает файлы, поэтому и
хранить ему нечего.

Установка
---------
1. Распакуйте содержимое архива в корень сайта (обычно public_html
   или www). Каталоги admin, api, assets, lib должны лежать рядом с
   index.php.

2. Заведите в панели хостинга базу данных MySQL и пользователя к ней.
   Запишите имя базы, имя пользователя и пароль.

3. Откройте в браузере  https://ваш-домен/install.php

   Установщик спросит:
     - доступ к базе данных;
     - название сайта и его адрес (из адреса собираются короткие ссылки);
     - пароль администратора.

   Он сам создаст таблицы и файл config.php.

4. УДАЛИТЕ ФАЙЛ install.php с сервера. Пока он лежит, любой, кто удалит
   config.php, сможет переустановить сайт заново. Админка будет
   напоминать об этом на главной странице сводки.

5. Зайдите в https://ваш-домен/admin/ и проверьте настройки.

Если на хостинге нет mod_rewrite
--------------------------------
Короткие адреса /p/КОД и /u/КОД делает файл .htaccess. Если Apache
игнорирует его или у вас nginx, работать будут прямые адреса вида
/p.php?c=КОД и /u.php?u=КОД, но выглядят они хуже. Правило для nginx:

    location ~ ^/p/([A-Za-z0-9]{3,16})/?$ { try_files $uri /p.php?c=$1; }
    location ~ ^/u/([A-Za-z0-9]{3,24})/?$ { try_files $uri /u.php?u=$1; }
    location ~ ^/(lib|config\.php|schema\.sql) { return 404; }

Обновление уже установленной сети
---------------------------------
1. Сделайте копию базы. Обновление меняет схему, и откатиться без копии
   будет нечем.

2. Перезапишите файлы новой версией, НЕ ТРОГАЯ config.php. По FTP это
   обычно «залить с заменой», в панели хостинга — распаковать архив
   поверх.

3. Откройте https://ваш-домен/update.php и нажмите «Обновить».

   Скрипт добавит недостающие таблицы и колонки, уберёт файлы прежних
   версий (старую общую ленту, скрипт сканера, обработку изображений) и
   перечислит то, что осталось лишним. Ваши записи, позывные и настройки
   он не трогает.

   Запускать можно сколько угодно раз: всё сделанное пропускается.

4. Если у вас есть консоль, то же самое делает команда:

       php update.php

Что скрипт НЕ делает намеренно:

  - не удаляет таблицу images и каталог uploads, оставшиеся от версий с
    картинками. Это ваши данные, и решение за вами. Команды для удаления
    он подскажет;
  - не меняет ваши настройки. Если название сети осталось прежним или в
    настройках всё ещё стоит ограничение записей в час, поправьте это в
    админке — новые значения по умолчанию действуют только для новых
    установок.

Кнопка магазина
---------------
На главной есть кнопка «Доступно в RuStore». Адрес ссылки правится в админке:
«Содержимое» -> «Связь и документы» -> «Ссылка на приложение в RuStore».
Очистите поле — кнопка исчезнет.

Значок на кнопке нейтральный, наш. Если нужен официальный бейдж RuStore,
положите его картинкой в /assets/rustore.svg — движок подставит её сам,
править код не придётся.

Раздача приложения с сайта
--------------------------
Прямая загрузка APK остаётся запасным путём: она нужна тем, у кого нет
магазина. В архиве есть каталог app с файлом radioinformator-<версия>.apk. Пока он
на месте, на главной странице сама появляется кнопка загрузки с указанием
веса сборки; уберёте файл — исчезнет и кнопка. Надпись на кнопке
правится в админке, раздел «Содержимое».

Чтобы выложить новую сборку, положите её в тот же каталог: берётся самый
свежий по времени файл *.apk. Старый можно удалить.

Если хостинг отдаёт APK как текст и браузер открывает его вместо
загрузки, значит игнорируется .htaccess. Для nginx добавьте:

    types { application/vnd.android.package-archive apk; }

Люди будут ставить приложение из файла, а не из магазина, поэтому на
телефоне придётся один раз разрешить установку из этого источника —
Android спросит сам.

Подключение приложения
----------------------
В приложении ЭФИР откройте настройки и укажите адрес сайта. Если в
админке задан токен, впишите и его. Приложение само прочитает лимиты и
сетку каналов с /api/limits.php.

В сборке с сайта адрес уже указан — https://radioinformator.ru. Менять
его нужно, только если вы поднимаете свою сеть на своём домене.

Что важно понимать
------------------
  - Кодовое слово пользователя на сервер не попадает. Восстановить его
    невозможно — ни вам, ни ему. Это не недоработка, а замысел.
  - Списка людей и поиска по людям нет. Личная лента открывается только
    по коду, который приходит вместе с передачей по Wi-Fi.
  - Файлы не принимаются. Только текст.
  - Личные сообщения через сайт не проходят: они шифруются в приложении и
    живут только в эфире. Сервер их не видит и хранить не может.
  - Визитка на странице ленты (имя, телефон, почта, сайт, Telegram, VK)
    заполняется самим человеком из приложения и по умолчанию пуста.
    Формы для неё на сайте нет намеренно: кодовое слово телефон не
    покидает, а без него править чужую визитку было бы нечем защитить.
