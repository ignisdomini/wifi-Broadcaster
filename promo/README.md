# Промо-сайты ЭФИРа

[![Лицензия Apache 2.0](https://img.shields.io/badge/лицензия-Apache%202.0-blue.svg)](../LICENSE)

Пять одностраничников под пять доменов для приложения
[ЭФИР](https://www.rustore.ru/catalog/app/ru.radioinformator.efir). Каждый
обыгрывает своё название и показывает продукт с одной стороны — вместе они
закрывают всю идею, а по отдельности не выглядят копиями друг друга.

**Ни сборки, ни зависимостей, ни единого внешнего запроса.** Каждый сайт —
один `index.html`: системные шрифты, иконка внутри страницы, скриптов пара
десятков строк. Открывается двойным щелчком, заливается копированием папки.

## Как заливать

Содержимое **папки** кладётся в корень своего домена. Каждый сайт —
один-единственный `index.html`, без сборки, зависимостей и внешних запросов:
шрифты системные, иконка встроена в страницу, скриптов от силы три десятка
строк. Ничего настраивать не нужно.

```
budvefire/index.html   ->  budvefire.ru/index.html
naefire/index.html     ->  naefire.ru/index.html
pishivefir/index.html  ->  pishivefir.ru/index.html
slushaiefir/index.html ->  slushaiefir.ru/index.html
yavefire/index.html    ->  yavefire.ru/index.html
```

Файл `index.html` в корне этой папки — служебный, только для просмотра всех
пяти сразу. На домены он не заливается.

## Локальный просмотр

Запуск «efir-promo», порт 8813 — открывается список всех пяти.

## Куда ведут кнопки

На каждой странице два пути установки, и оба нужны:

- **«Доступно в RuStore»** — главный. Магазин сам обновляет приложение, и
  человеку не надо разрешать установку из неизвестного источника.
  Ссылка: `https://www.rustore.ru/catalog/app/ru.radioinformator.efir`
- **«Скачать с сайта»** — запасной, ведёт на `radioinformator.ru`, где лежит
  APK. Нужен тем, у кого магазина нет или он не работает.

Обе кнопки стоят дважды: в первом экране и в финальном призыве. До низа
страницы дочитывает тот, кто уже решился, — возвращать его наверх за ссылкой
невежливо.

**Значок на кнопке магазина наш, нейтральный.** Фирменный знак RuStore по
памяти не рисуется — если понадобится официальный бейдж, возьмите его из
брендбука магазина и замените `<svg class="store-i">` на `<img>`. Стили
подходят и тому и другому.

## Что учтено

- Верстка проверена на 375 px: горизонтальной прокрутки нет ни на одной странице.
- Всё движение отключается при `prefers-reduced-motion` — целиком, одним правилом.
- Заголовки и описания для соцсетей (`og:title`, `og:description`) заполнены
  по-разному на каждом сайте: ссылки не должны выглядеть одинаково.
- Тексты не врут: дальность названа честно, ограничения тоже.

## Грабли, на которые уже наступили

`.hero` с классом `wrap` перебивал горизонтальные поля обёртки сокращённой
записью `padding: 4.5rem 0 3rem`. На широком экране это незаметно, а на
телефоне текст упирался в самый край. Поэтому у первых экранов теперь
`padding-block`, а не `padding`.
